================================================================================
VERION AI - HACKATHON MENTOR SESSION PREPARATION CHEAT-SHEET
Problem Statement (2B): Multi-Source Ingestion into a Single Verifiable Document
================================================================================

1. PROBLEM STATEMENT AND PROPOSED APPROACH
--------------------------------------------------------------------------------
* Problem Statement:
  - Incident investigations rely on fragmented, heterogeneous data (scanned PDFs/OCR,
    chat transcripts, raw system logs) across different security classification levels.
  - Current tools hallucinate, lack provenance/audit trails, or fail to correlate facts
    across different sources.

* Proposed Approach (Verion AI):
  - A local-first, multi-source ingestion and verification pipeline.
  - Normalizes and chunks heterogeneous evidence, applying cryptographic fingerprinting
    (SHA-256).
  - Enforces RBAC/ABAC clearance levels with dynamic redaction to prevent data spillage.
  - Uses an entity-resolution and cross-examination engine to detect conflicts/
    contradictions between sources.
  - Synthesizes a unified, cited investigation narrative where every single claim
    links directly back to its verifiable source chunk and hash.


2. KEY PERFORMANCE INDICATORS (KPIs)
--------------------------------------------------------------------------------
* Citation & Attribution Rate: 100% of claims in the generated report traceable to an
  exact source chunk and cryptographic hash.
* Cross-Source Conflict Detection Rate: Successfully flag inconsistencies between human
  testimony (interviews) and immutable records (system logs).
* Classification Security / Zero Spillage: 100% dynamic redaction compliance when
  documents are accessed below required clearance levels.
* Hallucination Rate: Near-zero via strict retrieval grounding and claim validation.
* Time-to-Dossier: Reduce manual multi-source reconciliation time from hours to under
  30 seconds.


3. EXPECTATIONS AND DELIVERABLES
--------------------------------------------------------------------------------
* Expectations:
  - Fully working, end-to-end prototype runnable locally in 9–11 hours.
  - No mandatory dependency on paid external APIs (on-prem / local-first architecture).

* Deliverables:
  - Interactive Web Dashboard:
      * Multi-source upload zone (PDF, interview chats, syslogs).
      * Clearance level switcher (Unclassified vs. Secret) with real-time redaction preview.
      * Side-by-side Conflict Detection & Evidence Inspection radar.
      * Unified chronological incident timeline.
  - Synthesized Dossier with Provenance: Real-time narrative with interactive citation pills.
  - Exportable Cryptographic PDF Report: Downloadable incident report stamped with an audit
    trail and SHA-256 integrity seal.
  - Bundled Benchmark Demo Dataset: A realistic cybersecurity/incident dataset demonstrating
    immediate contradiction detection.


4. EXPECTED OUTCOMES
--------------------------------------------------------------------------------
* Demonstrated Feasibility: Proof that heterogeneous evidence can be reconciled locally
  with zero data spillage.
* Defensible Auditability: Complete legal/compliance audit trail from source byte to
  final report statement.
* Immediate Value to Investigators: Automated detection of false statements or conflicting
  evidence across logs and interviews.


5. TECHNICAL ARCHITECTURE & STACK
--------------------------------------------------------------------------------
* Frontend:
  - React + Vite (Fast, responsive, modern dark-mode forensics dashboard).
  - Lucide Icons & CSS (High-polish incident response UI).

* Backend:
  - FastAPI (Python 3.11) (High-performance async REST API, auto OpenAPI docs).
  - Uvicorn (ASGI server).

* Ingestion & Parsers:
  - PDF & OCR: pdfplumber / pypdf + pytesseract fallback for scanned sheets.
  - Logs: Regex & structured JSON log parser.
  - Interviews / Chat: Transcript parser extracting speaker, timestamp, and statement.

* Data & Verification Layer:
  - Vector Store & Embeddings: In-memory FAISS / ChromaDB + lightweight embeddings
    (sentence-transformers/all-MiniLM-L6-v2).
  - Provenance Engine: SHA-256 chunk hashing and source mapping table.
  - Security Engine: RBAC clearance level filter & PII/sensitive text redaction module.

* AI & Verification Core:
  - LLM Engine: Pluggable local LLM via Ollama (Llama 3.2 / Mistral / Qwen) with instant
    fallback toggle to fast cloud inference (Groq / Gemini) during development.
  - Verification Logic: Rule-based timestamp correlation + LLM cross-examination prompt
    for conflict detection.

* Report Generation:
  - WeasyPrint / ReportLab / HTML-to-PDF for downloadable, digitally stamped PDF dossiers.
